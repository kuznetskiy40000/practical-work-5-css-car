# Практическая работа 5 — CSS Car

Машинка шириной **200px**, полностью нарисованная HTML-элементами и CSS.

- при загрузке выезжает с левого края экрана;
- останавливается в 50px от правого края;
- фон-пейзаж также собран средствами CSS;
- предусмотрена настройка `prefers-reduced-motion`.

Откройте `index.html` в браузере.
